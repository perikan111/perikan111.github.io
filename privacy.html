プライバシー ポリシー（国会解説ツール）

最終更新日：2026年11月11日

1. このツールについて

「国会解説ツール」（以下「本ツール」）は、YouTube チャンネル「国会を読む」の運営者が、自分で作った動画を自分のチャンネルにアップロードするためだけに使うツールです。一般の利用者には提供していません。

2. 使う Google のデータ

本ツールは、運営者自身が許可した場合に限り、次の YouTube の権限を使います。

  • YouTube アカウントの表示：接続先のチャンネル名とチャンネル ID を読み、投稿先が正しいかを確かめるため
  • YouTube 動画の管理：作った動画・サムネイル・字幕をアップロードし、公開日時を設定するため

これ以外の Google アカウントの情報（メール、連絡先、閲覧履歴など）は読みません。

3. データの保存と共有

  • Google から受け取る認証情報は、運営者の PC と、運営者が管理する GitHub の暗号化された保存場所（Secrets）にだけ保存します。
  • 取得したデータを第三者に売ったり、渡したり、広告に使ったりはしません。
  • 本ツールが Google API から受け取った情報の使用と移転は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。

4. アクセスの取り消し

本ツールへのアクセスは、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。
